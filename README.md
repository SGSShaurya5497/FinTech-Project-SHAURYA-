# SHAURYA — Your Financial Intelligence, Simplified.

SHAURYA is an all-in-one financial intelligence platform for India. It streamlines personal finance tracking, provides alternate credit score assessment, promotes interactive financial literacy, and enables peer-to-peer (P2P) lending/borrowing options in a single consolidated dashboard.

## Key Features

1. **Alternate Credit Score Generation**: Evaluates creditworthiness using alternate data profiles and assets rather than relying solely on traditional scores.
2. **Comprehensive Net Worth Tracking**: Consolidates balances, mutual funds, equities, and ETF investments into a single unified space.
3. **SHAURYA Financial Academy**: Personalized educational modules structured inside a card grid covering mutual funds, equity shares, debt ratio, and insurance concepts.
4. **P2P Borrowing & Lending Marketplace**: Features a credit-score adapted EMI calculator, interactive loan application requests, and a decentralized lending funding simulator.

## Run Locally

Follow these steps to spin up the local development environment:

```bash
# Install dependencies
yarn install

# Start the local development server
yarn start
```
